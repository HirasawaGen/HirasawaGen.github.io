在CA-Nav的基础做出改进的几点想法

发表于 2025-11-02 更新于 2025-11-06

针对 CA-Nav 原框架的不足，提出三项轻量化优化：一是通过 LLM 对任务合理性打分，动态分配步数，避免无效探索；二是让位置约束优先，agent 先找目标地点再寻物，贴合人类导航逻辑；三是对无位置约束的任务，用 LLM 补全物体最可能出现的场景，提升搜索效率。

合理性参数

在CA-Nav原论文中，将一句话划分为多个子任务，然后再将子任务划分为约束，让agent根据约束来执行导航任务，而每个子任务的最大步数都是固定的25步。

我的想法是这样的，在子任务执行之前，先根据LLM对句子合理性打分。（不需要）

例如：

  • “在办公室中找一台打印机”：

    • 位置约束：办公室
    • 对象约束：打印机
    • 合理性：较高
    • 步数：50步

  • “在卧室中找一头狮子”：

    • 位置约束：卧室
    • 对象约束：狮子
    • 合理性：较低
    • 步数：10步

  • “在火星表面找一头猛犸象”：

    • 位置约束：火星表面
    • 对象约束：猛犸象
    • 合理性：极低
    • 步数：0步（直接跳过）

对位置约束的优化

在CA-Nav中，三个约束之间几乎可以说是“各过各的”，几乎无关联。

于是会出现这样一个情况，若需要执行的任务是：“去厨房找一把刀”，agent会去主动找刀，但是并不会主动去找厨房，而是通过VQA模型实时判断当前位置是不是厨房。

换算成人的思维，当人听到**“去厨房找一把刀”**，人肯定是优先去厨房，其次再找刀。因此可以得到如下优化方案：

对无位置约束的优化

在CA-Nav中，三个约束并不是必须都得有。例如当执行任务：**“去找一张床”**时。

未标明地点是卧室，假如当前agent在客厅，agent并不会去主动找卧室，只会先在当前位置也就是客厅中找床。

因此可以先通过大语言模型判断目标与位置的关联度，如果是杯子等与位置无关联的物体，使用原有的方法即可。

如果是找一口锅，一张床这种明显会与位置有关联的物体，则会将相应位置填入位置约束。
